### Bank Marketing Campaign EDA
Data Source : https://archive.ics.uci.edu/dataset/222/bank+marketing

#### Project Overview:
Exploratory Data Analysis (EDA) on a dataset from a bank’s marketing campaign to encourage clients to subscribe to a term deposit.

#### Key Insights:
- 1.8% of clients are defaulters.
- 11.81% of clients subscribed for the product — a relatively weak conversion rate.
- Suggests the bank could benefit from a more targeted marketing approach.

#### Tools Used:
- Python
- Pandas
- Seaborn
- Matplotlib
- VS Code
